# 2026-08-21 工作日志

## 修复：网络速度显示约为实际 2 倍（TUN 双计）

**根因**：`psutil.net_io_counters()` 默认聚合所有网卡。本机 Clash 类代理开了 TUN 模式（虚拟网卡 `Meta Tunnel`，IfType=53），同一份流量在「以太网」（Realtek 2.5GbE）与 `Meta` 各计一次 → 聚合值 ≈ 物理网卡 × 2。实测上传：修复前聚合 0.49MB/s vs 修复后物理网卡 0.26MB/s（≈1.9 倍）。

**修复**（v1.0.3 → v1.0.4）：
- `core/network_monitor.py`：新增 `GetAdaptersAddresses`（ctypes，只声明到 OperStatus 字段）识别物理网卡（IfType 6/71 + OperStatus up + 描述排除 virtual/tunnel/vmware/bluetooth 等关键词），缓存 120s；`_get_io_bytes()` 按口径统计（白名单 > 物理网卡 > 聚合兜底）。
- `config.py`：新增 `NETWORK_PHYSICAL_ONLY=True`（默认只统计物理网卡）、`NETWORK_INCLUDE_ONLY=[]`（网卡名白名单，优先）。
- 版本同步：`ui/version.py`、`README.md`、`CHANGELOG.md` → v1.0.4。

**注意**：结构体字段定义必须先 `class ...: pass` 再赋值 `_fields_`（ctypes 前向引用字符串写法 `POINTER("名")` 会导致段错误）；API 调用显式声明 argtypes 避免 64 位指针截断。

**验证**：物理网卡识别仅剩「以太网」；上传方向修复前后 ≈ 0.49 vs 0.26 MB/s；offscreen 完整采集链路 3 次正常，累计流量与以太网计数器一致。
